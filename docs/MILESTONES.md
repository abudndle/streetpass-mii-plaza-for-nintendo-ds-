# Development milestones

1. **Project bootstrap and validation**: repository structure, license/source provenance documentation, baseline host-side validation; then create an actual DS ROM skeleton with BlocksDS.
2. **Original game inventory and compatibility matrix**: catalog StreetPass Mii Plaza original features and lawful private assets, wireless capabilities, RAM and VRAM constraints; map shared Mii schema with Mii Maker DS.
3. **Plaza rendering and persistence**: rooms, multiple animated original Miis, touch menus, save data and progression, screenshot-backed emulator testing.
4. **Games and features**: implement the original included minigames, panels, puzzles, achievements and other original game functionality, including applicable regional and version differences.
5. **Wireless and background exchange**: research local DS/DSi packet exchange, authentication and 3DS compatibility; prototype launcher-integrated background operation and sleep-mode behavior; test real hardware and document limitations.
6. **Acceptance and packaging**: compare original and ported visuals and behavior, comprehensive host/emulator/hardware regression tests, appropriately licensed source distribution, private asset packaging instructions.

A milestone is only complete when actual implementation and evidence are committed. Placeholder graphics or menu-only prototypes do not satisfy feature parity.
