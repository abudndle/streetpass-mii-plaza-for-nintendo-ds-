# Research sources and boundaries

- [Waldy238/OpenPass](https://github.com/Waldy238/OpenPass): 3DS homebrew queue and network routing concepts. Its 3DS service calls cannot simply be compiled as DS code.
- [3ds-netpass/netpass](https://gitlab.com/3ds-netpass/netpass): network-based 3DS relay; GPLv3-or-later license. No code is copied into this repository.
- [yazidears/StreetPass](https://github.com/yazidears/StreetPass): iOS BLE presence app, not Nintendo 3DS StreetPass.
- [abudndle/mii-maker-ds](https://github.com/abudndle/mii-maker-ds): BlocksDS conventions and original Mii codec/transfer implementation.
- [Wikipedia: SpotPass and StreetPass](https://en.wikipedia.org/wiki/SpotPass_and_StreetPass): conceptual behavior.
- [DSWifi multiplayer guide](https://blocksds.skylyrac.net/dswifi/md_documentation_2local__multiplayer__mode.html): potential DS ↔ DS transport.
- [BlocksDS filesystem guide](https://blocksds.skylyrac.net/docs/guides/filesystem/): DLDI and DSi SD card behavior.

The goal is to adapt all feasible original Plaza games, visual interfaces, activity tracking, Mii visitors and progression to the DS/DSi, preserving behavior where possible while documenting hardware tradeoffs. This version has no original-game assets and no implemented minigames. No compatibility with a stock 3DS StreetPass service is claimed.
