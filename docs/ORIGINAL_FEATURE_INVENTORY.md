## Wireless and platform compatibility

Nintendo states that native StreetPass is exclusive to Nintendo 3DS software. A DS executable cannot claim compatibility with the native StreetPass OS service. A DS-to-DS exchange would instead be a custom protocol; cross-protocol communication must be proven independently on hardware. Background behavior requires separate launcher/system-level support, if feasible. Original dual-screen UI needs DS-resolution adaptation, and stereoscopic 3D has no native DS equivalent.

## Verification requirements for every feature

- Document original-version and region-specific behavior and lawful private resource provenance.
- Implement game behavior, persistence, UI and resource loading—not placeholder text as completion evidence.
- Add host tests, native DS build artifacts, emulator captures, and physical hardware verification where required.
- Never put original Nintendo ROMs, proprietary model/audio files, decrypted archives, or content-derived hashes in the public repo.
